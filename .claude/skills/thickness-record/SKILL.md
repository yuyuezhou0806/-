# 厚度原始记录模拟器

基于随机中位数生成器，用于模拟厚度原始记录数据。

## 与随机中位数生成器的区别

| 项目 | 随机中位数 | 厚度记录 |
|------|-----------|---------|
| 修约 | 修约到 0.2 | **不修约** |
| 平均显示 | 1 位小数 | **2 位小数** |

## 规则

1. **第1组**：在指定范围（默认 8.00 ~ 12.00）生成15个随机数，**每3个一列的列内偏差 ≤ 0.20（±0.10）**，**5个中位数差值 ≤ 0.10**。每列取中位值，5个中位值求算术平均（不修约），保留 2 位小数
2. **第2组**：基于第1组每个数 +0.15~0.25 随机偏移，同样计算
3. 平均值尽量避免 .00 结尾

## 启动方式

### 方式一：网页版（推荐）

```bash
start thickness_record_demo.html
```

### 方式二：命令行

```bash
python thickness_record.py
python thickness_record.py --seed 42
python thickness_record.py --range1 149.60 150.00 --offset 0.15 0.25
```
