# 试样长宽模拟器

## 规则

1. **第1组**：在指定范围（默认 149.60 ~ 150.00）生成15个随机数，**每3个一列的列内偏差 ≤ 0.20（±0.10）**。每列取中位值，5个中位值求平均，修约到 0.2
2. **第2组**：基于第1组每个数 +0.15~0.25 随机偏移，同样每列取中位值，5个中位值求平均，修约到 0.2

## 算法说明

- 第1组每组随机选一个中心值，在中心值 ±0.10 范围内生成3个数，保证列内偏差 ≤ 0.20
- 第2组每个数 = 第1组对应数 + random(偏移下限, 偏移上限)
- 中位值 = 每列3个数排序后的中间值（纯中位数）
- 最终平均值修约到指定步长（默认 0.2）

## 启动方式

### 方式一：网页版（推荐）

浏览器打开 `random_median_demo.html`，点"生成"按钮即可：

```bash
start random_median_demo.html
```

### 方式二：命令行

```bash
python random_median.py                          # 默认参数
python random_median.py --seed 42                # 固定种子复现
python random_median.py --range1 149.60 150.00 --offset 0.15 0.25 --round-step 0.2
```
